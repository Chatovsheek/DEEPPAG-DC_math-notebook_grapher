# DEEPPAG-DC: Математический блокнот + графер
**DEEPPAG-DC math notebook with grapher**

================================================================================
              МАТЕМАТИЧЕСКИЙ БЛОКНОТ v4 — краткая инструкция
================================================================================

ЧТО ЭТО?
Лёгкий редактор математических документов в браузере.
Слева — текст с HTML и LaTeX, справа — готовый документ с формулами и графиками.
Один HTML-файл, интернет нужен только при первом запуске (MathJax и math.js с CDN).

================================================================================
БЫСТРЫЙ СТАРТ
================================================================================

1. Открыть файл в Chrome / Edge / Firefox
2. Писать текст и формулы в левой панели
3. Смотреть результат справа (обновляется через 300 мс)
4. Сохранить: "💾 Сохранить" (HTML) или "📑 PDF" (печать)

================================================================================
ФОРМУЛЫ
================================================================================

Встроенная формула (в строке текста):    \( E = mc^2 \)
Отдельная формула (на всю ширину):       \[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]
Разрыв страницы при печати:              <div class="pb"></div>

Формулы рендерятся через MathJax 3 в векторный SVG — при печати PDF чёткие.

================================================================================
ГРАФИКИ (кнопка "📈 График")
================================================================================

1) ЯВНЫЕ ФУНКЦИИ y = f(x):
   Пример: sin(x)*3; x^2/4
   Несколько функций через точку с запятой.

2) НЕЯВНЫЕ КРИВЫЕ F(x,y) = G(x,y):
   Пример: x^2/16 + y^2/9 = 1
   Рисуются методом marching squares.

3) ПАРАМЕТРИЧЕСКИЕ x(t), y(t):
   Пример: 5*cos(t), 5*sin(t)
   Опционально: x(t), y(t), t0, t1 — диапазон t вручную.

ДИАПАЗОНЫ ОСЕЙ:
   Поля "x от, до" и "y от, до" (например, -6,6).

КАК ЭТО В ТЕКСТЕ:
   График вставляется как тег <plot>:
   <plot f="sin(x)*3; x^2/4" x="-6,6" y="-5,8"></plot>
   При рендере заменяется на векторный SVG с осями, сеткой, легендой.

ПОДДЕРЖИВАЕТСЯ:
   - Разрывы на асимптотах (ветви не соединяются)
   - Красивая сетка с шагом
   - Оси через ноль
   - Легенда с LaTeX-формулами
   - Автомасштаб по диапазонам

================================================================================
СОХРАНЕНИЕ И ЗАГРУЗКА
================================================================================

💾 Сохранить   — документ как HTML с датой в имени
📂 Загрузить   — .html, .htm, .txt, .tex
📄 Новый       — очистить поле (с подтверждением)
📑 PDF         — окно печати → "Сохранить как PDF"

АВТОСОХРАНЕНИЕ:
   каждые 300 мс текст пишется в localStorage браузера.
   При следующем открытии документ восстановится.

================================================================================
ОСОБЕННОСТИ PDF
================================================================================

- Векторные формулы (SVG от MathJax) — чёткие на любом масштабе
- Векторные графики (SVG) — не мылятся
- Разрыв страницы — тег <div class="pb"></div>
- Умные разрывы: формулы, таблицы, графики, пункты списков не рвутся
- Заголовки не отрываются от следующего блока
- Цвета сохраняются (print-color-adjust: exact)

Печать идёт через window.print() — стандартное окно браузера,
где нужно выбрать "Сохранить как PDF".

Кнопки в диалоге графика — предпросмотр обновляется автоматически

================================================================================
ОГРАНИЧЕНИЯ
================================================================================

1. Интернет нужен при первом запуске — MathJax и math.js грузятся с CDN.
   Обходной путь: скачать библиотеки локально и заменить src в <script>.

2. <plot> требует числовых значений. Все переменные, кроме x, y, t, — числа.

3. Неявные кривые: сетка 140x140. Сложные кривые с острыми углами
   могут быть чуть угловатыми.

4. Графики не интерактивны: нет зума, наведения, тултипов. Статичный SVG.
